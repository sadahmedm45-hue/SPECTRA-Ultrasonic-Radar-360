# Start Here

1. Read [`README.md`](README.md) for the project overview.
2. Check the actual wiring in [`hardware/wiring/`](hardware/wiring/).
3. Upload [`firmware/arduino/SPECTRA_Radar_Arduino.ino`](firmware/arduino/SPECTRA_Radar_Arduino.ino).
4. Install dependencies with `python -m pip install -r requirements.txt`.
5. Run `python software/python/radar_gui.py`.
6. Use [`docs/installation-guide.md`](docs/installation-guide.md) and [`docs/user-manual.md`](docs/user-manual.md) for further instructions.
