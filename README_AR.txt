SPECTRA / 360° ULTRASONIC RADAR
=================================

ملفات المشروع:
- radar_gui.py              واجهة Python (Tkinter) والتحكم عبر Serial.
- Radar_360_Arduino.ino     كود Arduino Uno للمحرك 28BYJ-48 والحساس HC-SR04.
- assets/profile_avatar.png صورة الملف الشخصي الدائرية في عمود البيانات الأيمن؛ الضغط عليها يفتح معلومات المشروع.
- assets/nexus_profile_dark.png صورة بطاقة معلومات المشروع التي تظهر عند النقر على الصورة.
- requirements.txt          مكتبات Python المطلوبة.

1) التوصيلات الصحيحة (Arduino Uno)
----------------------------------
28BYJ-48 مع لوحة ULN2003:
  N1 / IN1 -> D12
  N2 / IN2 -> D11
  N3 / IN3 -> D10
  N4 / IN4 -> D9
  VCC لوحة ULN2003 -> مصدر مناسب لنسخة المحرك (غالبًا 5V لهذه النسخة)
  GND لوحة ULN2003 -> GND مشترك مع Arduino

HC-SR04:
  TRIG -> D8
  ECHO -> D7
  VCC  -> 5V
  GND  -> GND

Buzzer:
  الطرف الموجب -> D13
  الطرف السالب -> GND

ملاحظات الطاقة:
- تحقّق من جهد المحرك المطبوع على المحرك/لوحته قبل التغذية.
- إذا استخدمت مصدرًا خارجيًا للمحرك، اربط GND المصدر مع GND الأردوينو.
- لا تغذِّ المحرك من منفذ 5V في الأردوينو إذا كان يسحب تيارًا أعلى من قدرة المنفذ؛ استخدم مصدرًا مناسبًا للوحة ULN2003.

2) منطق العمل
-------------
- يتحرك المحرك الخطوي من 0° إلى 360° ثم يرجع إلى 0°، ويكرر المسح.
- HC-SR04 يقيس المسافة خلال المسح.
- عند ظهور قراءة صحيحة داخل حد المسافة المختار، يتوقف المحرك عند الزاوية الحالية ويعمل البزر؛ تتحول شاشة الرادار ولوحة التنبيه إلى الأحمر.
- يظل النظام متوقفًا حتى يمر زمن التوقف الأدنى الذي تحدده من الواجهة، ثم يتأكد من اختفاء الجسم عبر 4 قراءات متتالية خارج منطقة الكشف.
- إذا ظل الجسم ضمن حد الكشف، يبقى المحرك متوقفًا والبزر يعمل حتى يختفي الجسم.
- زمن التوقف في الواجهة هو مدة دنيا، وليس أمرًا يجبر المحرك على الحركة بينما الجسم لا يزال موجودًا.
- حد الكشف قابل للضبط من 2 إلى 400 سم. المدى الفعلي والدقة يعتمدان على السطح والزاوية والضوضاء؛ المدى النظري للحساس لا يضمن نفس الأداء لكل الأجسام.

3) بروتوكول Serial
-------------------
السرعة: 115200 baud.

أوامر Python -> Arduino:
  SPEED,1..10     سرعة المحرك (1 أبطأ، 10 أسرع)
  LIMIT,2..400    حد مسافة الإنذار بالسنتيمتر
  HOLD,2..30      زمن التوقف الأدنى بالثواني
  PAUSE           إيقاف المسح يدويًا
  RESUME          استئناف المسح يدويًا
  PING            طلب رسالة READY

بيانات Arduino -> Python:
  RADAR,angle,distance,detected,direction,paused,speed,holdRemainingMs,limit,holdSeconds
  EVENT,OBJECT_DETECTED,angle,distance
  EVENT,OBJECT_CLEARED,angle,distance
  CONFIG,...
  READY,...
  ERROR,...

إذا لم تصلك بيانات RADAR، فتأكد من اختيار منفذ COM الصحيح ومن أن Serial Monitor في Arduino IDE مغلق.

4) تثبيت وتشغيل Python على Windows
----------------------------------
افتح طرفية VS Code داخل مجلد المشروع وشغّل:
  python -m pip install -r requirements.txt

ثم:
  python radar_gui.py

Tkinter يأتي عادةً ضمن توزيعة Python الرسمية على Windows. إذا ظهر خطأ متعلق بـ tkinter، ثبّت إصدار Python الرسمي الذي يتضمن Tcl/Tk.

5) رفع كود Arduino
------------------
- افتح Radar_360_Arduino.ino في Arduino IDE.
- اختر Board: Arduino Uno.
- اختر المنفذ الصحيح ثم Upload.
- أغلق Serial Monitor، وشغّل radar_gui.py.
- اختر المنفذ نفسه من SERIAL LINK واضغط CONNECT.

6) ملاحظات مهمة
---------------
- الواجهة تعرض محاكاة حركة فقط عندما يكون Arduino غير متصل. بعد الاتصال، زاوية الشعاع تأتي من القياسات الفعلية للأردوينو.
- HC-SR04 ليس حساس زاوية؛ الزاوية هي موضع المحرك وقت قياس المسافة.
- القيمة الاسمية 4096 half-steps/revolution مستخدمة كبداية. قد يختلف العدد الفعلي قليلًا حسب نسخة 28BYJ-48 وعلبة التروس؛ عايرها إذا لم تكمل دورة فعلية عند 360°.
- لم يتم اختبار التوصيلات على عتاد فعلي في هذه البيئة.

7) تصميم الواجهة
----------------
- تشغل شاشة الرادار الدائرية الكبيرة نحو ثلثي مساحة النافذة، مع شبكة خلفية، حلقات مدى، تدريج زاوي كثيف، شعاع مسح متحرك وقطاع ضوئي خلفه.
- يشغل عمود البيانات الأيمن نحو الثلث المتبقي، ويحتوي صورة الطالب القابلة للنقر، معلومات المشروع، زاوية المسح، المسافة، حالة الإنذار، الإعدادات وسجل Serial.
- عند الاتصال الفعلي، يتبع الشعاع زاوية المحرك التي يرسلها Arduino. في وضع DEMO تتحرك المحاكاة لعرض الواجهة فقط.
- صورة المعاينة موجودة باسم preview.png داخل مجلد المشروع.
