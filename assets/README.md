# 🎨 Project Assets

This folder contains reusable visual assets for the SPECTRA RADAR application and documentation.

- [`images/`](images/) — interface previews, author profile, project banner, and reference images.
- [`icons/`](icons/) — small SVG icons for project sections.

The Python GUI loads the profile image and project information card from `assets/images/`. Keep these files in place when running the application from the repository structure.
