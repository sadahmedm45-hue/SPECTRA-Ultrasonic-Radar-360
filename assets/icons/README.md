# 🧩 Section Icons

This directory provides lightweight SVG icons used in the repository documentation. The icons are simple vector assets and render directly in browsers that support SVG.

| Icon | Section | File |
|---|---|---|
| ⚙️ | Arduino firmware | `firmware.svg` |
| 🖥️ | Python software | `software.svg` |
| 🔌 | Hardware | `hardware.svg` |
| 🖼️ | Images and assets | `assets.svg` |
| 📚 | Documentation | `docs.svg` |
| ✅ | Testing | `tests.svg` |
| 🔗 | Serial connection | `serial.svg` |

These icons are decorative navigation aids; the text labels remain the authoritative names of each section.
