# 🧪 Test Records

This directory contains the communication reference transcript and a repeatable bench-test checklist.

- [`serial-test.txt`](serial-test.txt) — representative message sequence / protocol reference. It is a sample, not a captured measurement from a verified physical test.
- [`test-results.md`](test-results.md) — test procedure, expected behavior, and status tracking.

For reproducible results, record the motor voltage, motor speed setting, detection limit, hold time, target material, target distance, test date, and observed outcome.
